# RU
- Провайдер не должен вызывать CRUD (Create, Read, Update, Delete) напрямую у другого провайдера обходя интерфейс VFSFrontend, в том числе самого себя.
  - Маршрутизатор VFS, кроме самой маршрутизации, выполняет важные проверки и регистрации событий. Если провайдер вызывается напрямую, это может привести к эксплойту и нарушению консистентности ACL правил.
  - Провайдер, если хочет обратиться к другому провайдеру, обязан сначала получить [BoundVFS] инстанс через контекст, а затем вызывать методы этого инстанса.
  - Пример правильного вызова из провайдера
  ```go
	  boundfs, ok := vfs.BoundVFSFromContext(ctx)
		if !ok {
			return nil, nil
		}
		myURI, err := boundfs.SelfURI("/testest")
		if err != nil {
			return nil, err
		}
		boundfs.Delete(ctx, myURI)
	```

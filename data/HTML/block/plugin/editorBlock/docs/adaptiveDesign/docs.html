Настройка адаптивного дизайна

Интерфейс позволяет управлять расположением элементов и настраивать, как они используют доступное пространство.

Для построения раскладки используются два режима:

  • Grid - расположение элементов по колонкам и строкам.
  • Flex - расположение элементов преимущественно в одном направлении.

Настройки разделены на основные и дополнительные. Основные предназначены для быстрого изменения раскладки, а дополнительные - для более точной настройки.

Пользователь работает с понятными полями и переключателями, а необходимые CSS-свойства изменяются автоматически.

Grid

Grid используется, когда элементы нужно расположить по колонкам и строкам. Он подходит для структуры страницы, панелей, карточек и других сеток.

Основные настройки

В основных настройках находятся параметры, которых достаточно для большинства простых сеток.

Готовые раскладки

Готовая раскладка позволяет не создавать структуру вручную. При выборе варианта автоматически создаются необходимые колонки, строки и области.

Доступны варианты:

  • Страница - шапка, основной контент и низ.
  • Меню слева - добавляется отдельная левая колонка.
  • Меню справа - дополнительная колонка располагается справа.
  • Две панели - основной контент находится между двумя боковыми колонками.
  • Панель управления - структура из меню и нескольких областей содержимого.
  • Карточки - автоматически изменяемое количество одинаковых карточек.

Например, раскладка «Меню слева» создаёт:

Шапка
Меню | Основной контент
Низ

После применения готовой раскладки её можно изменять обычными или дополнительными настройками.

Сетка

Поля «Колонки» и «Строки» определяют основную структуру сетки. При увеличении значения создаются дополнительные колонки или строки, при уменьшении - лишние удаляются. 

Колонки       [3]
Строки        [2]
Расстояние    [10]

«Расстояние» задаёт одинаковый промежуток между всеми колонками и строками.

Пример результата:

grid-template-columns: 1fr 1fr 1fr;
grid-template-rows: 1fr 1fr;
column-gap: 10px;
row-gap: 10px;

Адаптация

Параметр «Подбирать колонки автоматически» используется, когда количество колонок не должно быть фиксированным. 

☑ Подбирать колонки автоматически

Мин. ширина    [220]
Макс. ширина   [400]

Минимальная ширина определяет, насколько узкой может стать колонка. Максимальная ширина ограничивает её увеличение.

Если места становится меньше, Grid уменьшает количество колонок. Если места становится больше - помещает больше колонок в одну строку.

Например:

grid-template-columns:
    repeat(auto-fit, minmax(min(100%, 220px), 400px));

Выбранный элемент

Основные настройки выбранного элемента позволяют изменить, сколько колонок и строк он занимает. 

Колонок    [2]
Строк      [1]

Например, значение «Колонок: 2» растягивает элемент сразу на две соседние колонки. 

grid-column-end: span 2;

Дополнительные настройки Grid

Дополнительные настройки нужны для точного управления сеткой. Здесь можно отдельно изменять каждую колонку и строку, управлять автоматическим заполнением и точно размещать элементы.

Колонки и строки

Каждая колонка отображается отдельной строкой. Для неё можно независимо указать размер и единицу измерения. 

1    [220] [px]    ↑ ↓ ×
2    [1]   [fr]    ↑ ↓ ×
3    [25]  [%]     ↑ ↓ ×

+ Добавить колонку

Значение определяет размер, а соседний список - способ его измерения. Например, 220 px создаёт фиксированную колонку, а 1 fr позволяет колонке занять часть свободного пространства.

Для колонок доступны:

  • fr - доля свободного пространства;
  • px - фиксированный размер;
  • % - процент от размера контейнера;
  • rem - размер относительно основного размера текста;
  • vw - размер относительно ширины окна;
  • auto - размер определяется автоматически.

Например:

200px 1fr 2fr

преобразуется в:

grid-template-columns: 200px 1fr 2fr;

Строки изменяются таким же способом. Для них вместо vw доступно vh, то есть размер относительно высоты окна. 

1    [70] [px]    ↑ ↓ ×
2    [1]  [fr]    ↑ ↓ ×
3    [60] [px]    ↑ ↓ ×

+ Добавить строку

Кнопки ↑ и ↓ изменяют порядок колонки или строки. Кнопка × удаляет её. Кнопка добавления создаёт новую колонку или строку.

Таким способом можно, например, сделать фиксированную шапку и низ, оставив центральную часть растягиваемой: 

grid-template-rows: 70px 1fr 60px;

Автоматические колонки

Эти параметры уточняют работу автоматического подбора колонок.

Заполнение

«Заполнять место» использует auto-fit. Свободные колонки схлопываются, а существующие элементы могут занимать освободившееся пространство. 

repeat(auto-fit, ...)

«Сохранять колонки» использует auto-fill. Grid продолжает учитывать возможные пустые колонки, даже если в них пока нет элементов. 

repeat(auto-fill, ...)

Минимальная ширина

Определяет минимальный допустимый размер автоматической колонки. Например, при значении 220 колонка старается не становиться уже 220 px. Если места недостаточно, количество колонок уменьшается.

Максимальный размер

Определяет, как колонка использует оставшееся пространство.

  • Растянуть - колонка занимает доступную долю пространства.
  • По содержимому - размер определяется содержимым.
  • Макс. содержимое - колонка ориентируется на полный размер содержимого без лишнего сжатия.

Например:

repeat(auto-fit, minmax(220px, 1fr));

Такой вариант создаёт столько колонок шириной минимум 220 px, сколько помещается, после чего свободное место распределяется между ними.

Расстояния

В основных настройках одно поле изменяет расстояние сразу по горизонтали и вертикали. В дополнительных их можно разделить. 

Горизонтально    [20]
Вертикально      [10]
Внутри           [15]

«Горизонтально» изменяет расстояние между колонками: 

column-gap: 20px;

«Вертикально» изменяет расстояние между строками: 

row-gap: 10px;

«Внутри» задаёт свободное пространство между границами всей сетки и её содержимым: 

padding: 15px;

Заполнение

Параметр «Порядок» определяет, куда Grid автоматически помещает элементы, для которых позиция не задана вручную.

По строкам

Элементы сначала заполняют текущую строку, затем переходят на следующую. 

grid-auto-flow: row;

По колонкам

Элементы сначала располагаются сверху вниз, а затем переходят в следующую колонку. 

grid-auto-flow: column;

Без пустых мест

Grid может использовать свободные ячейки, которые появились между ранее размещёнными элементами. Более поздний небольшой элемент может быть перемещён в подходящее свободное место. 

grid-auto-flow: row dense;

Вариант «По колонкам без пустот» работает аналогично, но основным направлением являются колонки. 

grid-auto-flow: column dense;

Выбранный элемент

Дополнительные настройки позволяют не только изменить размер элемента, но и точно указать его место в сетке. 

Колонка          [2]
Строка           [1]
Занять колонок   [2]
Занять строк     [1]

Колонка

Определяет колонку, с которой начинается элемент. При выборе «Автоматически» место выбирает сам Grid. 

grid-column-start: 2;

Строка

Аналогично определяет начальную строку элемента. 

grid-row-start: 1;

Занять колонок

Определяет ширину элемента в количестве колонок. Значение 2 означает, что элемент займёт две колонки. 

grid-column-end: span 2;

Занять строк

Определяет высоту элемента в количестве строк. 

grid-row-end: span 2;

Flex

Flex используется для расположения элементов преимущественно в одном направлении - горизонтально или вертикально.

Основные настройки

Основные настройки позволяют быстро выбрать направление, расстояние, перенос и выравнивание элементов.

Готовые раскладки

Готовые варианты устанавливают сразу несколько связанных параметров.

  • В ряд - элементы располагаются горизонтально.
  • В столбец - элементы располагаются вертикально.
  • Панель кнопок - элементы распределяются по ширине и выравниваются по центру.
  • С переносом - элементы автоматически переходят на следующую строку при нехватке места.

Расположение

«Направление» определяет основную ось расположения элементов. 

Направление    [По горизонтали ▼]

Можно выбрать:

  • по горизонтали;
  • по вертикали;
  • горизонтально в обратном порядке;
  • вертикально в обратном порядке.

Например:

flex-direction: row;

«Расстояние» задаёт промежуток между соседними элементами. 

gap: 10px;

«Переносить элементы» позволяет переносить элементы на новую строку или колонку, когда им перестаёт хватать места. 

flex-wrap: wrap;

Выравнивание

«По направлению» определяет распределение элементов вдоль основной оси.

Например, «По краям»:

justify-content: space-between;

Первый элемент будет находиться у начала контейнера, последний - у конца, а свободное место распределится между ними.

«Поперёк» управляет положением элементов относительно второй оси.

Например:

align-items: center;

При горизонтальном направлении элементы будут выровнены по центру по вертикали.

Выбранный элемент

Для отдельного элемента можно выбрать простой способ управления размером.

  • По содержимому - размер зависит от содержимого.
  • Занять свободное место - элемент расширяется на доступное пространство.
  • Равная доля - элементы делят доступное место.
  • Заданный - используется указанный размер.

Например:

Размер    [Заданный ▼]
Размер    [120]

Результат:

flex: 0 0 120px;

Дополнительные настройки Flex

Дополнительные настройки Flex позволяют отдельно управлять поведением всего контейнера и каждого выбранного элемента.

Контейнер

Направление

Определяет основное направление расположения элементов. В отличие от простого выбора можно также использовать обратный порядок. 

flex-direction: row;
flex-direction: column;
flex-direction: row-reverse;
flex-direction: column-reverse;

Перенос

Определяет поведение элементов, когда они перестают помещаться в одну строку или колонку.

«Без переноса» оставляет все элементы на одной линии. 

flex-wrap: nowrap;

«Переносить» разрешает создавать дополнительные линии. 

flex-wrap: wrap;

«Перенос наоборот» также переносит элементы, но дополнительные линии располагаются в обратном направлении. 

flex-wrap: wrap-reverse;

Расстояние

Задаёт одинаковый промежуток между Flex-элементами. 

gap: 10px;

Распределение

Управляет распределением свободного пространства вдоль основного направления.

  • В начале - все элементы располагаются в начале.
  • По центру - группа элементов располагается по центру.
  • В конце - элементы смещаются к концу.
  • По краям - первый и последний элементы располагаются у краёв.
  • Равномерно - пространство распределяется вокруг элементов.
  • Одинаковые промежутки - между элементами и краями создаются одинаковые промежутки.

Изменяется:

justify-content: ...;

Выравнивание

Определяет положение всех элементов поперёк основной оси.

  • Растянуть - элементы растягиваются по доступному размеру.
  • В начале - располагаются у начала поперечной оси.
  • По центру - располагаются по центру.
  • В конце - располагаются у противоположного края.
  • По тексту - элементы выравниваются относительно базовой линии текста.

Изменяется:

align-items: ...;

Строки

Эта настройка используется, когда Flex содержит несколько линий после переноса элементов.

Она определяет, как сами линии распределяются по свободному пространству контейнера.

  • Растянуть - линии занимают доступное пространство.
  • В начале - линии собираются в начале.
  • По центру - линии располагаются по центру.
  • В конце - линии располагаются в конце.
  • По краям - свободное пространство находится между линиями.
  • Равномерно - пространство распределяется вокруг линий.

Изменяется:

align-content: ...;

Выбранный элемент

Эти настройки применяются только к выбранному Flex-элементу и позволяют точно определить его поведение внутри контейнера.

Расширение

Определяет, может ли элемент занимать свободное пространство. Чем больше значение относительно соседних элементов, тем большую часть свободного места он получает. 

flex-grow: 1;

Например, если у одного элемента значение 1, а у другого 2, второй получает в два раза большую долю распределяемого свободного пространства.

Сжатие

Определяет, насколько элемент может уменьшаться, когда всем элементам не хватает места. 

flex-shrink: 1;

Значение 0 запрещает обычное Flex-сжатие элемента. Положительные значения разрешают ему уменьшаться.

Базовый размер

Задаёт исходный размер элемента до распределения свободного или недостающего пространства. 

flex-basis: 200px;

После этого Flex может увеличить или уменьшить размер в зависимости от значений расширения и сжатия.

Выравнивание

Позволяет изменить поперечное выравнивание только выбранного элемента, не меняя остальные элементы контейнера.

«Автоматически» использует общее выравнивание контейнера. Остальные варианты позволяют растянуть элемент или расположить его в начале, по центру или в конце. 

align-self: center;

Порядок

Позволяет изменить визуальную последовательность Flex-элементов, не меняя их положение в HTML. 

order: 2;

Элементы с меньшим значением располагаются раньше, а с большим - позже. По умолчанию используется значение 0.

Основные и дополнительные настройки

Основные настройки предназначены для наиболее частых действий: выбора готовой раскладки, количества элементов сетки, направления, переноса и простого изменения размеров.

Раздел «Дополнительные» по умолчанию скрыт. Его можно раскрыть, когда требуется вручную настроить отдельные колонки и строки, автоматическое заполнение, точное положение Grid-элементов или поведение отдельных Flex-элементов.

Таким образом, для обычной настройки не требуется знать CSS, но при необходимости интерфейс позволяет управлять основными параметрами Grid и Flex отдельно.

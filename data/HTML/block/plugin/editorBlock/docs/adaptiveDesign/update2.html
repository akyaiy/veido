Размеры экрана

Добавлены диапазоны ширины экрана. Вкладка «Все размеры» хранит базовые настройки, а отдельные диапазоны - изменения для конкретной ширины.

Для диапазона можно задать название, минимальную и максимальную ширину, создать копию, удалить его или сбросить изменения.

Пример:

Mobile: 0-640
Tablet: 641-1024
Desktop: 1025+

Базовые свойства и переопределения

Свойства имеют три состояния:

  • База - значение из «Все размеры»;
  • Наследуется - используется базовое значение;
  • Изменено - значение переопределено в текущем диапазоне.

Кнопка «Сбросить» удаляет изменение конкретного свойства и возвращает наследование.

Ограничения изменений в диапазонах

В отдельных диапазонах можно менять только CSS-свойства. Настройки, которые создают, удаляют или перестраивают HTML-элементы, скрываются.

Таким образом, HTML остаётся общим, а адаптивность задаётся CSS.

Работа рабочей области с диапазонами

Во вкладке «Все размеры» ширину рабочей области можно менять свободно. При изменении ширины автоматически показывается подходящее состояние breakpoint.

В отдельном диапазоне изменение размера ограничено его границами.

Например, для 600-900px ширина не может выйти за 600-900px.

Размер выбранного элемента

Добавлены:

Мин. ширина
Макс. ширина

Они задают min-width и max-width выбранного элемента и могут отдельно изменяться в breakpoint.

Ограничения выбранного элемента

Добавлены:

  • минимальная и максимальная высота;
  • пропорции 1:1, 4:3, 16:9;
  • управление переполнением.

Используются CSS-свойства min-height, max-height, aspect-ratio и overflow.

Видимость элемента

Элемент можно скрыть только в нужном диапазоне.

Например:

Все размеры: видим
Mobile: скрыт

Для скрытия используется display: none.

Варианты элемента

Можно сохранить текущее CSS-состояние выбранного элемента как вариант.

Вариант можно:

  • переименовать;
  • применить;
  • удалить.

Это позволяет быстро переключаться между сохранёнными состояниями элемента.

Плавное расстояние

Расстояние между элементами можно изменять плавно между минимальным и максимальным значением.

Например:

gap: clamp(8px, 2vw, 24px);

Это позволяет менять расстояние без дополнительных breakpoint.

Адаптивный текст

Добавлены настройки:

  • обычный перенос;
  • разрыв длинных слов;
  • запрет переноса;
  • многоточие;
  • скрытие или прокрутка переполнения;
  • ограничение количества строк.

Используются overflow-wrap, white-space, text-overflow и line-clamp.

Реакция на размер родителя

Элемент может менять поведение в зависимости от ширины родительского контейнера.

Можно задать ширину, после которой:

  • расположение становится вертикальным;
  • включается перенос;
  • элемент скрывается.

Это соответствует логике container queries.

Responsive media

Для изображений и видео добавлены адаптивные настройки.

Для изображений доступны:

  • src;
  • srcset;
  • sizes;
  • object-fit;
  • loading.

Для видео используются источник и режим отображения.

Проверка адаптивности

Редактор автоматически проверяет ширины от 320px до 1200px.

Проверяется:

  • переполнение контейнера;
  • выход элементов за границы.

В результате показываются ширины, на которых найдены проблемы.

Стресс-тест текста

Стресс-тест временно заменяет содержимое элементов длинным текстом, словами без пробелов, числами и длинными подписями.

После этого запускается проверка адаптивности. Повторное нажатие возвращает исходный текст.

Обычная ширина автоматических колонок

Для автоматических Grid-колонок добавлено значение «Обычная ширина».

Теперь используются:

Мин. ширина
Обычная ширина
Макс. ширина

Значения проверяются так:

минимальная <= обычная <= максимальная

Обычная ширина используется как дополнительный параметр настройки автоматических колонок.

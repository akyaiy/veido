Grid

Grid подходит, когда элементы нужно расположить по колонкам и строкам. Например: страница с шапкой, меню и основным содержимым или сетка карточек.

Основные

В интерфейсеЧто делаетЗначенияCSS
Готовая раскладкаПрименяет готовую структуру и сразу меняет несколько параметров.Страница, меню слева, меню справа, две панели, панель управления, карточкиgrid-template-columns, grid-template-rows, grid-column, grid-row
КолонкиЗадаёт количество колонок сетки.1-12grid-template-columns
СтрокиОпределяет расположение нескольких строк элементов при переносе.1-12grid-template-rows
РасстояниеЗадаёт расстояние между элементами.0 px и большеcolumn-gap и row-gap
Подбирать колонки автоматическиАвтоматически меняет количество колонок в зависимости от доступной ширины.Включено / выключеноgrid-template-columns: repeat(auto-fit / auto-fill, minmax(...))
Мин. ширинаЗадаёт минимальную ширину автоматически создаваемой колонки.Число в pxМинимум внутри minmax()
Макс. ширинаОграничивает максимальную ширину автоматически создаваемой колонки.Число в pxМаксимум внутри minmax()

Дополнительные

Эти свойства находятся в нижнем раскрывающемся разделе «Дополнительные» и по умолчанию не занимают место в панели.

В интерфейсеЧто делаетЗначенияCSS
Список колонокПозволяет отдельно задать размер каждой колонки.Для каждой: число + fr / px / % / rem / vw / autogrid-template-columns
Список строкПозволяет отдельно задать размер каждой строки.Для каждой: число + fr / px / % / rem / vh / autogrid-template-rows
Добавить / удалить / переместить колонкуИзменяет количество и порядок колонок.Изменение состава и порядка спискаgrid-template-columns
Добавить / удалить / переместить строкуИзменяет количество и порядок строк.Изменение состава и порядка спискаgrid-template-rows
Заполнение автоматических колонокОпределяет, как сетка создаёт и заполняет автоматические колонки.Заполнять место / сохранять колонкиauto-fit / auto-fill
Горизонтальное расстояниеЗадаёт расстояние между колонками.0 px и большеcolumn-gap
Вертикальное расстояниеЗадаёт расстояние между строками.0 px и большеrow-gap
ВнутриЗадаёт внутренний отступ от краёв контейнера.0 px и большеpadding
Порядок заполненияОпределяет, в каком порядке элементы автоматически занимают свободные ячейки.По строкам / по колонкам / без пустых местgrid-auto-flow

Flex

Flex подходит, когда элементы нужно расположить в одном основном направлении - например, в ряд или в столбец.

Основные

В интерфейсеЧто делаетЗначенияCSS
Готовая раскладкаПрименяет готовую структуру и сразу меняет несколько параметров.В ряд / в столбец / панель кнопок / с переносомflex-direction, flex-wrap, justify-content, align-items, gap
НаправлениеОпределяет, располагаются элементы горизонтально или вертикально.По горизонтали / по вертикали / горизонтально наоборот / вертикально наоборотflex-direction
РасстояниеЗадаёт расстояние между элементами.0 px и большеgap
Переносить элементыРазрешает перенос элементов на новую строку при нехватке места.Включено / выключеноflex-wrap
По направлениюРаспределяет элементы вдоль основного направления.В начале / по центру / в конце / по краям / равномерно / одинаковые промежуткиjustify-content
ПоперёкВыравнивает элементы поперёк основного направления.Растянуть / в начале / по центру / в концеalign-items

Дополнительные

Эти свойства находятся в нижнем раскрывающемся разделе «Дополнительные» и по умолчанию не занимают место в панели.

В интерфейсеЧто делаетЗначенияCSS
НаправлениеОпределяет, располагаются элементы горизонтально или вертикально.row / column / row-reverse / column-reverseflex-direction
ПереносОпределяет, могут ли элементы переноситься на следующую строку.Без переноса / переносить / перенос наоборотflex-wrap
РасстояниеЗадаёт расстояние между элементами.0 px и большеgap
РаспределениеОпределяет распределение свободного места между элементами.Начало / центр / конец / по краям / равномерно / одинаковые промежуткиjustify-content
ВыравниваниеОпределяет выравнивание элементов внутри контейнера.Растянуть / начало / центр / конец / по текстуalign-items
СтрокиОпределяет расположение нескольких строк элементов при переносе.Растянуть / начало / центр / конец / по краям / равномерноalign-content

В интерфейсеЧто делаетЗначенияCSS

# rightPanelTabs

## Назначение

Этот модуль отвечает за переключение вкладок на правой панели редактора. Он позволяет отображать нужные секции настроек (текст, элемент, атрибуты, CSS, JS) и скрывать неактивные.

## Когда используется

Используется при взаимодействии с правой панелью, когда пользователю нужно переключить режим редактирования выбранного элемента.

## Как работает

1. Пользователь кликает по одной из вкладок на правой панели.
2. Модуль считывает идентификаторы целевых панелей из атрибута `right-panel-tab`.
3. Все остальные панели внутри правой панели скрываются.
4. Выбранные панели становятся видимыми.

## Компоненты

- Вкладки правой панели (`.rightPanelTab`) — интерактивные элементы для переключения разделов.
- Обработчик переключения (`handleRightPanelTabClick`) — функция, управляющая отображением панелей.

## Пример

Пользователь кликает на вкладку «Css», после чего скрываются прочие секции правой панели и отображается блок `cssEditor`.

## Ограничения

Модуль отвечает только за переключение видимости панелей и не управляет содержимым самих секций.

## Детали реализации

На элементы `.rightPanelTab` вешаются слушатели клика, которые считывают значения `right-panel-tab` и меняют свойство `display` у соответствующих блоков.

# cssEditor

## Назначение

Этот модуль отвечает за редактирование CSS-стилей текущего элемента или модуля. Он позволяет задавать правила через визуальную панель со свойствами и значениями для различных селекторов.

## Когда используется

Используется при настройке внешнего вида элементов, когда нужно добавить или изменить инлайн-стили, CSS-правила для классов, ID, тегов, псевдоклассов или медиазапросов.

## Как работает

1. Пользователь выбирает элемент в рабочей области.
2. Модуль отображает таблицу CSS-свойств, разбитую по типам селекторов (`element`, `id`, `class`, `tag`, `attribute`, `pseudo`, `media`).
3. Пользователь вводит или изменяет пару «свойство-значение» (`property` / `value`).
4. После правки изменения сохраняются и применяются к стилям текущего модуля.

## Компоненты

- Панель стилей (`#cssPanel`) — таблица с секциями под разные типы CSS-селекторов.
- Инпуты свойств и значений — поля для ввода CSS-правил (`property` и `value`).
- Синхронизатор стилей — передаёт и сохраняет обновлённые правила в структуре модуля.

## Пример

Пользователь выбирает секцию `Inline стиль` и задаёт `color: red`, или переходит в секцию `Псевдокласс` и прописывает `:hover` правила для кнопки.

## Ограничения

Модуль управляет только CSS-стилями и селекторами, связанными с текущим модулем и выбранным элементом.

## Детали реализации

Внутри модуля обрабатывается ввод из таблицы стилей, формируются CSS-правила и результат передаётся в данные текущего модуля.

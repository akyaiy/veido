# modalWindows

## Назначение

Этот модуль отвечает за всплывающие окна интерфейса: уведомления, подтверждения и ввод данных.

## Когда используется

Используется для сообщений об ошибках или действиях, а также для запросов подтверждения или текста у пользователя из других модулей редактора.

## Как работает

1. Модуль формирует задачу для нужного окна и помещает её в очередь.
2. `alert` показывает краткое уведомление и автоматически скрывается через несколько секунд.
3. `confirm` и `prompt` работают через отдельную очередь и возвращают Promise с результатом выбора или введённого значения.
4. После обработки окна очередь продолжает выполняться.

## Компоненты

- `alert` — окно уведомления.
- `confirm` — окно подтверждения.
- `prompt` — окно ввода текста.
- Очереди задач — последовательная обработка нескольких запросов.
- Callback-обработчики — передача результата обратно вызывающему коду.

## Пример

Интерфейс вызывает `prompt('Введите ссылку')`, пользователь вводит значение, и Promise возвращает это значение вызывающему коду.

## Ограничения

Модуль не реализует сложную валидацию ввода и не предоставляет собственный UI-контейнер; он опирается на уже существующие элементы окна в шаблоне редактора.

## Детали реализации

Внутри модуля есть очереди `alertQueue` и `interactiveQueue`, обработчики кнопок OK/Cancel и экспорт методов `alert`, `confirm`, `prompt` в `window.editorBlock`.

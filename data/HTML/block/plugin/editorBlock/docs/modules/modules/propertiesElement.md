# propertiesElement

## Назначение

Этот модуль отвечает за настройку свойств выбранного элемента. Он нужен, когда требуется изменить размеры, отступы, цвет и другие параметры оформления.

## Когда используется

Используется при работе с элементом, когда нужно уточнить его внешний вид или поведение в текущем модуле.

## Как работает

1. Пользователь выбирает элемент в редакторе.
2. Модуль показывает доступные свойства и их текущее состояние.
3. После правки значения сохраняются и применяются к выбранному элементу.

## Компоненты

- Панель свойств — отображает параметры элемента.
- Редактирование значений — изменяет стили и атрибуты.
- Синхронизация — передаёт обновления в структуру редактора.

## Пример

Пользователь задаёт элементу отступы и цвет фона и сразу видит результат в визуальном режиме.

## Ограничения

Модуль работает только с теми свойствами, которые поддерживаются редактором.

## Детали реализации

Внутри модуля реализованы панели настроек, обработка значений и передача изменений в CSS-структуру текущего модуля.

# propertiesElement

## Назначение

Этот модуль отвечает за настройку свойств выбранного элемента. Он нужен, когда требуется изменить размеры, отступы, цвет, фон, рамку и другие параметры оформления.

## Когда используется

Используется при выделении элемента в визуальном режиме, когда нужно изменить его внешний вид или подготовить его к дальнейшей правке.

## Как работает

1. Пользователь выбирает элемент в визуальном редакторе.
2. Модуль получает выбранный элемент из текущего состояния редактора.
3. Для свойства вычисляется текущее значение из inline- или computed-style.
4. После правки новые значения применяются к элементу и синхронизируются с историей и другими панелями.

## Компоненты

- Панель свойств — отображает параметры элемента.
- Работа с выбранным элементом — чтение и запись стилей.
- Поддержка автодополнения/автовыбора — для классов, цветов и похожих значений.

## Пример

Пользователь задаёт элементу отступы, цвет фона и размер шрифта и сразу видит результат в визуальном режиме.

## Ограничения

Модуль работает с DOM-элементом и его стилями, а не с источником данных блока напрямую.

## Детали реализации

Внутри модуля реализованы функции чтения и записи стилей, подсказки для классов и цветов, а также интеграция с панелью выбора цвета и историей изменений.

# attributesElement

## Назначение

Этот модуль позволяет задавать HTML-атрибуты выбранного элемента. Он нужен, когда требуется дать элементу идентификатор, класс или другие параметры для дальнейшей работы с ним.

## Когда используется

Используется при настройке уже созданного элемента, когда нужно связать его с CSS, JavaScript или с другими частями текущего модуля.

## Как работает

1. Пользователь выбирает элемент в рабочей области.
2. Модуль показывает доступные атрибуты и их текущие значения.
3. После правки изменения сохраняются и становятся частью данных текущего модуля.

## Компоненты

- Панель атрибутов — отображает список доступных полей.
- Редактор значений — изменяет параметры элемента.
- Синхронизация с редактором — передаёт обновлённые данные в структуру модуля.

## Пример

Пользователь добавляет элементу id="hero" и класс "cta", чтобы позже стилизовать его через CSS.

## Ограничения

Модуль работает только с теми атрибутами, которые поддерживаются текущим редактором и выбранным элементом.

## Детали реализации

Внутри модуля хранится список атрибутов, обрабатываются изменения и результат передаётся в данные текущего модуля.

# blockPreview

## Назначение

Этот модуль переключает редактор в режим предпросмотра. Он нужен, когда требуется быстро оценить, как будет выглядеть результат без постоянного переключения между редактором и готовой страницей.

## Когда используется

Используется в процессе работы с модулем, когда нужно проверить итоговое оформление или структуру контента.

## Как работает

1. Пользователь включает режим предпросмотра.
2. Модуль скрывает инструменты редактирования и показывает итоговый результат.
3. При изменении содержимого preview обновляется вместе с текущим состоянием модуля.

## Компоненты

- Переключатель режима — включает и выключает предпросмотр.
- Область просмотра — показывает готовый результат.
- Синхронизация с контентом — отражает текущее состояние редактора.

## Пример

Пользователь внес изменения в текст и сразу видит, как они выглядят в финальном виде.

## Ограничения

Модуль не меняет структуру содержимого самостоятельно, а только переключает способ отображения.

## Детали реализации

Внутри модуля реализовано переключение между режимами редактирования и просмотра, а также обновление представления при изменении данных.

# blocksContainers

## Назначение

Этот модуль хранит данные о текущих модулях редактора и об их содержимом. Он нужен, чтобы разные части интерфейса могли работать с одними и теми же редакторскими данными.

## Когда используется

Используется при создании, открытии и переключении между редакторскими модулями.

## Как работает

1. При открытии или создании модуля его данные добавляются в контейнер.
2. Модуль хранит информацию о содержимом, связанном файле и текущем состоянии.
3. При переключении между модулями остальные компоненты получают доступ к нужным данным.

## Компоненты

- Хранилище модулей — список текущих редакторских модулей.
- Метаданные — имя, путь и состояние модуля.
- Доступ к содержимому — предоставляет данные для отображения и редактирования.

## Пример

Пользователь открывает несколько модулей, и каждый из них хранится в контейнере с собственными данными.

## Ограничения

Модуль хранит данные, но не отвечает за их визуальное отображение и не управляет самим интерфейсом.

## Детали реализации

Внутри модуля реализована структура хранения модулей и доступ к их содержимому.

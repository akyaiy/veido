# viewBlock

## Назначение

Этот модуль отображает активный модуль редактора в рабочей области. Он нужен, чтобы пользователь видел текущее содержимое выбранного модуля в одном месте.

## Когда используется

Используется при открытии и переключении между редакторскими модулями.

## Как работает

1. Модуль получает данные активного модуля.
2. Отображает их в рабочей области редактора.
3. При смене активного модуля обновляет содержимое и интерфейс.

## Компоненты

- Рабочая область — место отображения модуля.
- Загрузка данных — получает контент из хранилища.
- Обновление интерфейса — отражает текущий активный модуль.

## Пример

Пользователь выбирает вкладку с нужным модулем, и в центре редактора появляется его содержимое.

## Ограничения

Модуль не хранит данные сам по себе, а только отображает их.

## Детали реализации

Внутри модуля реализован рендер активного модуля и синхронизация с контейнером данных.

# viewBlock

## Назначение

Этот модуль отвечает за переключение режимов редактора в центральной панели: визуальный, MD и JS.

## Когда используется

Используется при выборе режима просмотра/редактирования и при переключении между блоками.

## Как работает

1. Модуль скрывает неактивные редакторы и показывает выбранный.
2. Для активного редактора добавляется класс `active`, а для кнопки режима — соответствующий активный стиль.
3. При выборе визуального режима вызывается событие `editorBlock:openLoadedBlock`, чтобы перезагрузить текущий блок и синхронизировать его содержимое.

## Компоненты

- `switchEditor` — функция переключения между редакторами.
- Кнопки режимов — `viewEditorButton`, `mdEditorButton`, `jsEditorButton`.
- Блок с редакторами — контейнер, в котором отображается только активный режим.

## Пример

Пользователь нажимает кнопку MD, и центральная панель переключается на текстовый редактор.

## Ограничения

Модуль не управляет содержимым блоков напрямую; он только меняет видимость и активность режимов.

## Детали реализации

Внутри модуля нет сложной логики хранения состояния, но он тесно связан с ядром `mainBlock` через события и DOM-структуру редактора.

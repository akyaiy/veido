# eventsEditor

## Назначение

Этот модуль отвечает за назначение обработчиков событий элементу. Он нужен, когда пользователь хочет связать действие интерфейса с JavaScript-функцией.

## Когда используется

Используется при настройке поведения элемента, например при добавлении клика, наведения или других событий.

## Как работает

1. Пользователь выбирает элемент.
2. Модуль показывает доступные события и связанные с ними действия.
3. После выбора функции она привязывается к элементу и становится частью его поведения.

## Компоненты

- Список событий — доступные обработчики.
- Привязка функции — назначает действие элементу.
- Переход к редактору кода — помогает редактировать функцию.

## Пример

Пользователь назначает клику по кнопке вызов функции открытия окна.

## Ограничения

Модуль работает только с теми событиями, которые поддерживаются редактором.

## Детали реализации

Внутри модуля реализована связь между интерфейсом, JavaScript-кодом и выбранным элементом.

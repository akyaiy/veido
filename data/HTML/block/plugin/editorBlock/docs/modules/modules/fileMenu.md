# fileMenu

## Назначение

Этот модуль отвечает за меню действий с текущим блоком редактора. Оно даёт доступ к основным операциям: сохранить, сохранить как, открыть существующий файл и создать новый блок.

## Когда используется

Используется при работе с текущим блоком, когда нужно быстро сохранить его состояние или открыть другой источник контента.

## Как работает

1. Пользователь открывает меню действий.
2. Модуль определяет выбранное действие по атрибуту `data-action`.
3. Для сохранения блок формируется в JSON-объект и скачивается как файл `block.json`.
4. Для открытия и создания блока вызываются соответствующие методы ядра редактора.

## Компоненты

- Кнопка меню — открывает/закрывает список команд.
- Список команд — содержит действия `save`, `saveAs`, `open`, `new`.
- Обработка выбора — запускает нужную операцию через `window.editorBlock`.

## Пример

Пользователь выбирает пункт `open`, вводит путь к файлу, после чего редактор загружает новый блок.

## Ограничения

Модуль не выполняет создание или чтение файлов сам по себе; он только запускает операции через интерфейс редактора.

## Детали реализации

Внутри модуля реализованы обработчики кликов по пунктам меню и простая логика закрытия меню при клике вне его.

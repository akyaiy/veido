# editorHistory

## Назначение

Этот модуль хранит историю изменений в редакторе. Он нужен, чтобы пользователь мог отменять правки и возвращаться к предыдущим версиям содержимого.

## Когда используется

Используется в процессе работы с редактором, когда нужно проверить или восстановить предыдущее состояние модуля.

## Как работает

1. После каждого изменения состояние сохраняется в историю.
2. Пользователь может перейти назад или вперёд по шагам.
3. Система восстанавливает нужную версию контента или структуры.

## Компоненты

- Хранилище состояний — сохраняет версии изменений.
- Навигация по истории — позволяет перемещаться по шагам.
- Восстановление состояния — возвращает нужную версию.

## Пример

Пользователь отменил последнюю правку и вернулся к предыдущему варианту страницы.

## Ограничения

История хранит только доступные шаги в текущем сеансе работы и не заменяет полноценную систему версий.

## Детали реализации

Внутри модуля реализованы сохранение состояний, управление стеком действий и восстановление нужной версии.

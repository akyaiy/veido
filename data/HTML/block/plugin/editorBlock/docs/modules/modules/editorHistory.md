# editorHistory

## Назначение

Этот модуль хранит историю изменений для текущего блока. Он даёт возможность откатывать и повторять правки как для визуального/MD-режима, так и для JS-редактора.

## Когда используется

Используется при вводе текста, изменении содержимого редакторов и переключении между блоками или режимами редакции.

## Как работает

1. Модуль собирает состояние активного редактора в снимок.
2. Для визуального и MD-режима история объединяет их в один стек `markupEditor`.
3. На каждом значимом действии состояние сохраняется в стек Undo, а при откате/повторе восстанавливается в нужный редактор.
4. Состояния ограничиваются лимитами по количеству блоков, редакторов и глубине стека.

## Компоненты

- Хранилище истории — `Map` по блокам и редакторам.
- Снимки состояния — текущее содержимое редакторов в момент сохранения.
- Undo/Redo — восстановление предыдущих и последующих состояний.
- Обработчики ввода — отслеживают изменения и группируют их в историю.

## Пример

Пользователь вводит текст в визуальном редакторе, затем нажимает кнопку назад — модуль восстанавливает предыдущий снимок состояния.

## Ограничения

История работает в пределах текущего сеанса и ограничена внутренними лимитами. Она не хранит данные на постоянной основе и не заменяет полноценную систему версий.

## Детали реализации

Внутри модуля реализованы функции `saveHistoryState`, `undoHistory`, `redoHistory`, `attachIframeHistoryEvents`, `setHistoryInitializing` и обработка событий ввода/клавиатуры.

# propertiesText

## Назначение

Этот модуль отвечает за форматирование текста в редакторе. Он нужен, когда требуется изменить внешний вид выделенного текста без правки структуры документа.

## Когда используется

Используется при работе с выделенным текстом, когда нужно задать жирность, курсив, подчёркивание, цвет, фон, выравнивание, списки или базовые размеры/шрифты.

## Как работает

1. Пользователь выделяет текст в визуальном или текстовом режиме.
2. Модуль определяет диапазон выделения и родительский элемент.
3. Для форматирования используются DOM-операции: обёртывание текста, изменение inline-стилей и работа с Range/Selection.
4. После применения изменений состояние синхронизируется с текущим редактором и сохраняется в истории.

## Компоненты

- Панель форматирования — кнопки и выпадающие списки для стилей текста.
- Работа с выделением — получение `Range`, определение родительского элемента и разбиение текстовых узлов.
- Применение стилей — изменение CSS-свойств и обёрток текста.

## Пример

Пользователь выделяет фрагмент и делает его жирным, меняет цвет или задаёт выравнивание.

## Ограничения

Модуль влияет на текстовые свойства и inline-структуру, но не заменяет полноценный визуальный редактор HTML.

## Детали реализации

Внутри модуля реализованы функции работы с `Selection`, `Range`, `TreeWalker`, а также логика создания/обновления DOM-узлов для форматирования текста.

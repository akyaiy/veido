# propertiesText

## Назначение

Этот модуль отвечает за форматирование текста в редакторе. Он нужен, когда требуется изменить внешний вид выделенного текста без правки самой структуры страницы.

## Когда используется

Используется при работе с текстом, когда нужно изменить шрифт, размер, стиль или выравнивание.

## Как работает

1. Пользователь выделяет текст в визуальном режиме.
2. Модуль показывает доступные параметры форматирования.
3. После изменения свойства применяются к выбранному тексту и сохраняются в текущем контенте.

## Компоненты

- Панель свойств — показывает доступные параметры.
- Форматирование — изменяет стиль текста.
- Синхронизация — сохраняет результат в структуру контента.

## Пример

Пользователь делает выделенный текст жирным или увеличивает его размер и сразу видит результат.

## Ограничения

Модуль влияет только на текстовые свойства и не меняет общую структуру элемента.

## Детали реализации

Внутри модуля реализованы действия форматирования и передача изменений в редакторский контент.

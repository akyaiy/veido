# mainBlock

## Назначение

Этот модуль задаёт основную структуру интерфейса редактора. Он создаёт рабочую область, объединяет части редактора и обеспечивает базовое взаимодействие между ними.

## Когда используется

Используется при открытии редактора и создании нового сеанса работы с модулем.

## Как работает

1. Система создаёт основной контейнер редактора.
2. Модуль формирует области интерфейса для размещения других модулей.
3. Подключенные части редактора используют созданную структуру для отображения и обработки действий.
4. При изменении состояния редактора модуль обеспечивает передачу данных между связанными частями.

## Компоненты

- Основной контейнер интерфейса - хранит структуру рабочей области редактора.
- Области размещения панелей - определяют расположение элементов интерфейса.
- Система синхронизации - обеспечивает обмен состоянием между `viewBlock` и `blocksContainers`.
- Обработка выделения - управляет выбранными элементами и текстом.

## Пример

Пользователь открывает редактор. Модуль создаёт рабочую область, после чего другие модули добавляют в неё панели, редакторы и инструменты.

## Ограничения

Модуль не хранит данные блоков и не отвечает за отдельные операции редактирования. Он только предоставляет структуру и базовую связь между компонентами редактора.

## Детали реализации

В модуле находятся создание структуры интерфейса, инициализация редактора, обработка общих событий и базовая логика взаимодействия между частями редактора.

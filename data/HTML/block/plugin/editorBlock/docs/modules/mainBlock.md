# mainBlock

## Назначение

Этот модуль является ядром редактора. Он управляет жизненным циклом блоков, загрузкой их содержимого в редакторы, синхронизацией между визуальным и MD-режимами, а также выделением элементов во встроенном iframe.

## Когда используется

Используется при инициализации редактора, открытии/создании/переключении блоков и во время работы с визуальным и текстовым редакторами.

## Как работает

1. При загрузке редактора модуль инициализирует базовую структуру блоков и вкладок.
2. При открытии блока он создаёт контейнер для HTML/CSS/JS, загружает данные и передаёт их в редакторы.
3. Визуальный редактор работает через iframe, куда подставляется HTML, CSS и JS блока.
4. Содержимое между визуальным, MD и JS-режимами синхронизируется через общие события и функции.
5. Модуль отслеживает выделение элементов, сохраняет состояние выделения и поддерживает режимы блокировки редактирования при отсутствии активного блока.

## Компоненты

- Управление блоками - создание, переключение, закрытие и сохранение состояния вкладок.
- Контейнеры блоков - хранение HTML, CSS и JS каждого блока в отдельных DOM-узлах.
- Визуальный редактор - iframe с превью и встроенными обработчиками событий.
- Синхронизация редакторов - обмен данными между viewEditor, mdEditor и jsEditor.
- Выделение элементов - overlay и сохранение выделенного элемента в текущем состоянии.
- Состояние активности - блокировка взаимодействия, если активный блок отсутствует.

## Пример

Пользователь открывает или создаёт новый блок. Модуль создаёт вкладку, подгружает содержимое в iframe и редакторы, а затем поддерживает их синхронизацию при любых изменениях.

## Ограничения

Модуль не отвечает за стилизацию отдельных панелей свойств или за специфические действия вставки элементов — эти задачи делегированы другим модулям.

## Детали реализации

В модуле находятся функции `openBlock`, `savePreviousBlock`, `syncEditors`, `restoreSelection`, `highlightElement`, `getEditorDocument`, `getEditorSelection` и логика управления active-блоком. Для взаимодействия с другими модулями он использует общие события `editorBlock:loaded`, `editorBlock:openLoadedBlock` и `editorBlock:elementSelected`.

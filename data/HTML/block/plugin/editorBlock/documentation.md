# Документация editorBlock

editorBlock - редактор HTML блоков, предназначенный для создания и редактирования HTML, CSS и JS кода через понятный интерфейс.



## Структура

### Верхняя панель
- Меню действий с файлами - управление файлами (сохранение, открытие итд.)
- Вкладки блоков - переключение между открытыми блоками
- Кнопки назад / вперёд - история изменений
- Кнопка предпросмотра - запуск режима просмотра блока

### Левая панель
- Кнопки вставки элементов - добавление HTML-элементов в блок

### Центральная панель
- Основной блок просмотра визуального режима, HTML-кода или JS-кода
- Кнопки переключения режимов (визуальный / HTML / JS)

### Правая панель
- Свойства текста - параметры текста (цвет, размер, шрифт)
- Свойства элемента - свойства стиля выбранного элемента
- Редактор событий - обработка JS событий элемента и назначение функций



## Файлы

### Основные
- JS-файл загрузки editorBlock - точка входа редактора, инициализация всех модулей
- Документация - описание структуры, модулей и логики проекта

### Основное
- mainBlock - основной каркас редактора, общая структура интерфейса и базовые стили/логика

### Работа с файлами
- fileMenu - меню действий с файлами (сохранение, открытие итд.)

### Управление блоками
- blocksTabs - вкладки открытых блоков
- viewBlocks - отображение и редактирование контента, и переключение режимов редактора (визуальный / HTML / JS)
- blocksContainers - хранение данных блоков (HTML, CSS, JS)
- editorHistory - история изменений (назад / вперёд)
- blockPreview - предпросмотр текущего блока

### Редакторы
- viewEditor - визуальный редактор блока (работа с элементами напрямую)
- htmlEditor - редактор HTML-кода
- cssEditor - редактор CSS-кода (в режиме таблицы)
- jsEditor - редактор JS-кода

### Редактирование
- insertingElements - вставка HTML-элементов в блок
- propertiesText - свойства текста (цвет, размер итд.)
- propertiesElement - свойства элемента (размеры, отступы итд.)
- attributesElement - HTML-атрибуты элемента (id, class, data-*)
- eventsEditor - JS события элемента (обработчики и назначение функций)

### Окна
- colorPicker - выбор цвета через окно
- contextMenu - контекстное меню (по правому клику)
- modalWindows - модальные окна (уведомления, подтверждения, ввод данных)

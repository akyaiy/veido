Поля страниц в структуре сайта

Функциональные - влияют на содержимое и работу страницы.

ID - идентификатор страницы.
Имя - имя страницы на английском для URL.
Название - обычное название страницы.
Пояснение - короткая заметка о странице.
Описание - подробное описание страницы и теги для поиска.
Типы - классы страниц для их разделения.
Тема - оформление страницы.
Статус - текущее состояние страницы.
Доступ / права - права доступа к странице.
Порядок - номер страницы среди дочерних страниц.
Перенаправление - переход на другую страницу.

Визуальные - влияют на отображение блока страницы в редакторе.

Положение - координаты X и Y в редакторе.
Вид - способ отображения информации о странице (например свёрнутый или развёрнутый).

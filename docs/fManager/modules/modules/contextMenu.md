# contextMenu

## Назначение

Этот модуль открывает быстрые команды для работы с файлом или папкой.

## Когда используется

Используется при правом клике по объекту, когда нужно выполнить действие без перехода в основные меню.

## Как работает

1. Пользователь нажимает на объект.
2. Модуль показывает список доступных команд.
3. После выбора команды запускается нужная операция.
4. Интерфейс обновляется в соответствии с результатом.

## Компоненты

- Список команд — набор доступных действий.
- Обработка клика — открывает меню для выбранного объекта.
- Вызов операций — запускает нужную команду.

## Пример

Пользователь выбирает папку и запускает из меню создание новой подпапки или переименование.

## Ограничения

Не все действия доступны для каждого объекта. Список команд зависит от типа объекта и прав доступа.

## Детали реализации

В модуле описываются команды меню, их привязка к объекту и передача действий в обработчики.

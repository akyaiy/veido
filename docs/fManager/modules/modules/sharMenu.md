# sharMenu

## Назначение

Этот модуль управляет доступом к файлу или папке.

## Когда используется

Используется, когда нужно дать или изменить права доступа другим пользователям.

## Как работает

1. Пользователь открывает настройки доступа.
2. Модуль показывает текущий список участников.
3. Можно добавить пользователя, удалить его или сменить уровень доступа.
4. После сохранения права применяются к объекту.

## Компоненты

- Список пользователей — участники доступа.
- Уровни доступа — права для каждого пользователя.
- Сохранение изменений — применяет новые права.

## Пример

Владелец папки дает редактору право на изменение файлов.

## Ограничения

Модуль не определяет правила безопасности сам по себе. Он только управляет настройкой доступа через интерфейс.

## Детали реализации

В модуле обрабатываются добавление и удаление пользователей, выбор прав и сохранение состояния доступа.

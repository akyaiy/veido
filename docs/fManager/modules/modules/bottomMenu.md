# bottomMenu

## Назначение

Этот модуль предоставляет быстрые действия над выбранным объектом.

## Когда используется

Используется, когда пользователь выбирает файл или папку и хочет выполнить над ними действие.

## Как работает

1. Пользователь выбирает объект.
2. Модуль показывает доступные действия.
3. После выбора действия запускается нужная операция.
4. Результат отображается в интерфейсе.

## Компоненты

- Поле имени — показывает текущий объект для действия.
- Кнопка действия — запускает операцию.
- Обработка выбора — связывает действие с выбранным элементом.

## Пример

Пользователь выделяет файл и запускает его удаление или переименование.

## Ограничения

Модуль не реализует все файловые операции самостоятельно. Он только подготавливает интерфейс и передаёт команду дальше.

## Детали реализации

В модуле находятся обработчики кнопок, привязка к выбранному объекту и передача команды в общую логику.

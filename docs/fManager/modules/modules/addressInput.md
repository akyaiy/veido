# addressInput

## Назначение

Этот модуль показывает текущий путь и помогает перейти к нужной папке или найти нужный объект.

## Когда используется

Используется при перемещении по файловой структуре и при навигации по каталогам.

## Как работает

1. Пользователь вводит путь или запрос.
2. Модуль обновляет текущее значение адреса.
3. Система загружает содержимое выбранной папки.
4. На экране отображается новая рабочая область.

## Компоненты

- Поле адреса — отображает текущий путь.
- Обработка ввода — принимает строку пути или запроса.
- Навигация по папкам — переключает текущий каталог.

## Пример

Пользователь вводит путь к папке с документами. После этого модуль показывает содержимое этой папки.

## Ограничения

Модуль не работает с файлами напрямую. Он отвечает только за навигацию и адрес.

## Детали реализации

В модуле обрабатывается ввод, нормализация пути и обновление состояния просмотра.

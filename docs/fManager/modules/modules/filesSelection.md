# filesSelection

## Назначение

Этот модуль отвечает за выбор файлов и папок в интерфейсе.

## Когда используется

Используется, когда пользователь хочет выделить один или несколько объектов для дальнейших действий.

## Как работает

1. Пользователь кликает по объекту или выделяет группу элементов.
2. Модуль добавляет их в текущий набор выбора.
3. Система использует выбранные элементы для операций копирования, перемещения, удаления и других действий.

## Компоненты

- Логика выделения — определяет, какие элементы выбраны.
- Хранение выбора — сохраняет текущий набор объектов.
- Обновление интерфейса — отражает выбранные элементы в UI.

## Пример

Пользователь выделяет два файла, а затем запускает их совместное перемещение.

## Ограничения

Модуль хранит только текущий выбор и не выполняет сами операции.

## Детали реализации

В модуле находятся правила выбора, обновление списка выбранных элементов и синхронизация с другими частями интерфейса.

# renameMenu

## Назначение

Этот модуль позволяет изменить имя файла или папки.

## Когда используется

Используется, когда пользователь хочет переименовать выбранный объект.

## Как работает

1. Пользователь запускает команду переименования.
2. Модуль показывает текущее имя.
3. Пользователь вводит новое имя.
4. Система применяет изменение и обновляет список объектов.

## Компоненты

- Окно ввода — принимает новое имя.
- Текущее имя — показывает старое значение.
- Подтверждение — применяет изменение.

## Пример

Пользователь переименовывает файл report.txt в report_v2.txt.

## Ограничения

Модуль не отвечает за сложные правила именования, если они проверяются на более высоком уровне.

## Детали реализации

В модуле обрабатывается ввод, проверка имени и передача команды на выполнение.

# filePropertiesMenu

## Назначение

Этот модуль показывает свойства файла или папки.

## Когда используется

Используется, когда нужно посмотреть характеристики объекта перед его изменением или переносом.

## Как работает

1. Пользователь выбирает объект.
2. Модуль собирает информацию о нём.
3. Открывается окно со свойствами.
4. Пользователь может изучить данные без изменения объекта.

## Компоненты

- Окно свойств — отображает информацию.
- Метаданные — показывают характеристики объекта.
- Доступ к данным — обеспечивает получение сведений для отображения.

## Пример

Пользователь открывает свойства папки и видит дату создания, размер и другие данные.

## Ограничения

Модуль не изменяет объект сам по себе. Он только показывает информацию.

## Детали реализации

В модуле формируется список свойств, выводятся метаданные и организуется отображение окна.

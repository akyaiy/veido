# historyFolder

## Назначение

Этот модуль хранит историю переходов по папкам и позволяет быстро вернуться к предыдущему месту.

## Когда используется

Используется, когда пользователь перемещается по нескольким каталогам и хочет вернуться назад.

## Как работает

1. При переходе по папке модуль добавляет путь в историю.
2. Пользователь может открыть предыдущий или следующий шаг.
3. Система обновляет текущий адрес и список файлов.

## Компоненты

- Список переходов — хранит путь навигации.
- Кнопки навигации — позволяют перейти назад или вперёд.
- Текущее положение — отражает активный каталог.

## Пример

Пользователь открыл папку с документами, затем перешёл в подпапку и вернулся назад по истории.

## Ограничения

История хранит переходы только в рамках текущего сеанса и не заменяет полноценную навигацию по файловой системе.

## Детали реализации

В модуле находятся правила добавления переходов, сохранение стека путей и обновление интерфейса навигации.

# mdEditor

## Назначение

Этот модуль отвечает за редактирование Markdown-контента модуля.

## Когда используется

Используется при изменении текстового содержимого блока.

## Как работает

1. Пользователь открывает редактор Markdown.
2. Модуль показывает текущий `content.md`.
3. После правки изменения сохраняются в редакторе.

## Компоненты

- Редактор текста — ввод и изменение Markdown.
- Синхронизация — передаёт данные в рабочую область.
- Поддержка структуры — помогает работать с контентом.

## Пример

Пользователь меняет текстовый блок на странице и сразу видит результат.

## Ограничения

Модуль отвечает только за текстовое содержание, а не за стили.

## Детали реализации

Здесь реализуется ввод, сохранение и передача Markdown-содержимого.

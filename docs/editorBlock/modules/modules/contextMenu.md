# contextMenu

## Назначение

Этот модуль открывает контекстное меню для работы с выбранным элементом. Он нужен, чтобы пользователь мог быстро вызвать действия без поиска их в панели инструментов.

## Когда используется

Используется при правом клике по элементу в рабочей области редактора.

## Как работает

1. Пользователь кликает по элементу правой кнопкой.
2. Модуль формирует список доступных команд.
3. После выбора команды запускается нужная операция или передаётся действие в общую логику редактора.

## Компоненты

- Список команд — набор доступных действий.
- Обработка клика — показывает меню в нужной точке интерфейса.
- Выполнение команды — запускает выбранную операцию.

## Пример

Пользователь вызывает меню у элемента и выбирает копирование, удаление или изменение свойств.

## Ограничения

Набор команд зависит от типа элемента, его состояния и текущего контекста редактора.

## Детали реализации

Внутри модуля описаны команды меню, правила их отображения и связь с обработкой действий редактора.

# fileMenu

## Назначение

Этот модуль отвечает за меню действий с текущим модулем редактора. Он нужен, чтобы пользователь мог запускать основные операции над файлом или модулем без перехода в другие панели.

## Когда используется

Используется при сохранении, открытии, создании и управлении файлами редактора.

## Как работает

1. Пользователь открывает меню действий.
2. Модуль показывает доступные команды.
3. После выбора команды выполняется нужная операция или передаётся в общую логику редактора.

## Компоненты

- Меню команд — список доступных действий.
- Обработка выбора — запускает нужную операцию.
- Синхронизация с редактором — обновляет состояние интерфейса.

## Пример

Пользователь сохраняет текущий модуль или открывает другой файл через меню.

## Ограничения

Модуль не выполняет операции над содержимым самостоятельно, а только запускает их.

## Детали реализации

Внутри модуля описаны команды меню, их поведение и передача действий в общую логику редактора.

# blocksTabs

## Назначение

Этот модуль отвечает за вкладки открытых модулей редактора. Он нужен, чтобы пользователь мог быстро переключаться между несколькими рабочими модулями.

## Когда используется

Используется при работе с несколькими открытыми модулями одновременно.

## Как работает

1. При открытии модуля создаётся вкладка.
2. Пользователь может переключаться между вкладками.
3. При выборе вкладки активный модуль меняется, и интерфейс обновляется.

## Компоненты

- Список вкладок — показывает открытые модули.
- Переключение — выбирает активную вкладку.
- Закрытие вкладки — удаляет модуль из списка.

## Пример

Пользователь открывает два модуля и переключается между ними через вкладки.

## Ограничения

Модуль управляет только интерфейсом вкладок и не отвечает за содержимое самих модулей.

## Детали реализации

Внутри модуля реализованы создание, переключение и закрытие вкладок.

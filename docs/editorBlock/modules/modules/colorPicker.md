# colorPicker

## Назначение

Этот модуль предоставляет интерфейс для выбора цвета. Он нужен, когда требуется задать цвет текста, фона, рамки или других свойств элемента.

## Когда используется

Используется при настройке стилей элемента в редакторе, когда пользователь выбирает цвет вручную.

## Как работает

1. Пользователь открывает выбор цвета.
2. Модуль показывает палитру и доступные способы ввода значения.
3. После выбора цвет передаётся в редактор и применяется к текущему свойству.

## Компоненты

- Палитра — показывает доступные цвета.
- Поля ввода — принимают HEX, RGB и другие значения.
- Передача значения — отправляет выбранный цвет в редактор.

## Пример

Пользователь выбирает зелёный оттенок для текста и сразу видит результат в визуальном режиме.

## Ограничения

Модуль отвечает только за выбор цвета и не выполняет расчёт или генерацию стилей.

## Детали реализации

Внутри модуля реализованы интерфейс выбора цвета, обработка ввода и передача значения в общую структуру редактора.

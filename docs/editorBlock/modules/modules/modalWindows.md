# modalWindows

## Назначение

Этот модуль отвечает за всплывающие окна интерфейса.

## Когда используется

Используется для уведомлений, подтверждений действий и ввода данных.

## Как работает

1. Система создаёт окно нужного типа.
2. Пользователь видит сообщение или вводит данные.
3. После подтверждения результат передаётся в редактор.

## Компоненты

- Окно уведомления — показывает сообщение.
- Окно подтверждения — запрашивает согласие.
- Окно ввода — принимает текст от пользователя.

## Пример

Пользователь подтверждает удаление элемента через всплывающее окно.

## Ограничения

Модуль не выполняет основную бизнес-логику, а только организует диалог.

## Детали реализации

Здесь реализуются типы окон, их содержимое и обработка ответов.

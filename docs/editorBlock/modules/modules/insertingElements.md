# insertingElements

## Назначение

Этот модуль вставляет новые HTML-элементы в текущий контент редактора. Он нужен, когда пользователь хочет добавить структуру или новый компонент в модуль.

## Когда используется

Используется при создании или расширении содержимого модуля.

## Как работает

1. Пользователь выбирает нужный элемент из списка.
2. Модуль вставляет его в активную позицию.
3. Изменение отражается в рабочей области и сохраняется в данных редактора.

## Компоненты

- Список элементов — доступные типы вставки.
- Вставка в позицию — определяет место добавления.
- Синхронизация — сохраняет результаты в редакторе.

## Пример

Пользователь добавляет в текущий модуль div-блок или изображение.

## Ограничения

Модуль работает только с теми типами элементов, которые поддерживаются редактором.

## Детали реализации

Внутри модуля реализованы правила вставки и обновление структуры контента.

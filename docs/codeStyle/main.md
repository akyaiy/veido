# Руководство по стилю frontend

## Что это такое

Этот раздел описывает правила оформления frontend-кода, структуры файлов, модулей и исходных файлов интерфейсной части проекта.

## Зачем нужен такой стиль

Единые правила помогают сохранить одинаковую структуру frontend-модулей, упростить чтение кода, поддержку интерфейса и совместную разработку.

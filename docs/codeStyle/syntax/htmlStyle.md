# Стилистика HTML

Правила оформления HTML кода проекта - структура, форматирование и использование разметки.



## Названия

- Использовать понятные и короткие названия.
- Название должно описывать назначение элемента.
- Использовать `camelCase` для названий.
- Избегать непонятных сокращений и не делать названия длиннее 3 слов.



## Пробелы и отступы

- Использовать (табуляцию) отступы в 4 пробела.
- Между элементами одного блока можно оставлять одну пустую строку, а между разными блоками HTML - 3 пустые строки.



## Комментарии

- Использовать комментарии для разделения логических блоков HTML.
- Между логическими блоками, разделёнными комментариями, оставлять 3 пустые строки.

Пример:

```html
<!-- Верхняя панель -->
<div id="topPanel">
</div>



<!-- Основная область редактора -->
<div id="mainPanel">
</div>
```



## HTML-классы

- Использовать правила названий из раздела [Названия](#названия).

Формат:

```html
<div class="userProfileBlock">
</div>
```



## HTML-атрибуты

- Использовать правила названий из раздела [Названия](#названия).
- Пользовательские атрибуты использовать в формате `kebab-case`.

Пример:

```html
<button id="saveFile" data-target="editor">
    Сохранить
</button>
```



## Inline CSS

Использование `style=""` разрешено только для динамических или специальных случаев.

Допустимо:

```html
<div style="display: none;">
</div>
```

Не рекомендуется:

```html
<div style="color: red; margin: 20px;">
</div>
```

Обычные стили должны находиться в CSS-файлах.



## JavaScript внутри HTML

JavaScript внутри HTML не используется.

Логика должна находиться в отдельных JS-файлах.

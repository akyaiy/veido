# Стилистика JavaScript

Правила оформления JavaScript кода проекта - структура, форматирование и организация кода.



## Названия

- Использовать понятные и короткие названия.
- Название должно описывать назначение элемента.
- Использовать `camelCase` для названий.
- Избегать непонятных сокращений и не делать названия длиннее 3 слов.

- Названия функций должны начинаться с глагола и описывать выполняемое действие.
- Для булевых переменных использовать префиксы `is`, `has`, `can`, `should`.

Пример:

```js
let selectedFile = null;
let isLoading = false;

function loadFile() {
}
```



## Пробелы и отступы

- Использовать (табуляцию) отступы в 4 пробела.
- Исключение: внутри комментариев использовать (табуляцию) отступы в 1 пробел.

Пример:

```js
/* ===
 * Состояние редактора
=== */
function createElement(tagName) {
    return document.createElement(tagName);
}
```

- Между строками одного логического блока можно оставлять одну пустую строку, а между разными блоками - 3 пустые строки.

Пример:

```js
/* ===
 * Состояние редактора
=== */

let selectedElement = null;

function createElement(tagName) {
    return document.createElement(tagName);
}



/* ===
 * Работа с событиями
=== */

function handleClick(event) {
    console.log(event.target);
}
```



## Комментарии

- Для комментариев, описывающих простую логику, использовать формат `// Комментарий`.

Пример:

```js
// Проверяем существование файла
if (!file) {
    return;
}
```

- Перед каждой переменной, обработчиком событий, логическим блоком или группой связанных элементов обязательно размещать комментарий.

Пример:

```js
// Текущий выбранный файл
let selectedFile = null;

// Координаты элемента
let elementX = 0;
let elementY = 0;

// Обработчики взаимодействия с редактором
element.addEventListener('click', handleClick);
element.addEventListener('input', handleInput);
element.addEventListener('keydown', handleKeyDown);
```

- Перед каждой функцией обязательно размещать комментарий.
- Для описания функций использовать комментарии формата `/* *** */`.
- Комментарий должен содержать описание назначения функции, принимаемых аргументов (если они есть), выполняемых действий и возвращаемого значения (если оно есть).

Формат:

```js
/* ***
 * functionName - описание назначения функции
 * описание принимаемых аргументов
 * описание выполняемых действий
 * ...
 * описание возвращаемого значения
*** */
```

Пример:

```js
/* ***
 * loadFile - загрузка файла
 * принимает путь к файлу
 * проверяет существование файла
 * загружает содержимое файла
 * возвращает объект файла
*** */
function loadFile(filePath) {
    if (!filePath) {
        return null;
    }

    return {};
}
```

- Для разделения логических блоков использовать комментарии формата `/* === */`.

Пример:

```js
/* ===
 * Работа с файлами
=== */

function loadFile() {
}
```



## Форматирование JavaScript

- Использовать фигурные скобки даже для однострочных условий и циклов.
- Использовать одинарные кавычки `' '`.
- Использовать `;` в конце каждой строки кода JavaScript.
- Не использовать сокращённые записи условий без необходимости.

Пример:

```js
if (isActive) {
    const fileName = 'test.txt';
    saveFile(fileName);
}

for (const file of files) {
    console.log(file);
}
```

- Каждую отдельную строку кода записывать с новой строки.
- Длинные условия переносить на несколько строк.
- Объекты и массивы форматировать с переносом строк при большом количестве элементов.

```js
if (
    isUserActive === 'active' &&
    hasPermission &&
    isFileLoaded &&
    !isLoading &&
    selectedFile !== null
) {
    const fileInfo = {
        name: 'test.txt',
        path: '/data/files/test.txt',
        size: 1024,
        type: 'document',
        permissions: [
            'read',
            'write',
            'delete'
        ]
    };

    openFile(fileInfo);
}
```

- После операторов `if`, `for`, `while`, `switch`, `catch` оставлять один пробел.
- Операторы сравнения, присваивания и арифметические операторы отделять пробелами.
- После запятых в параметрах функций и элементах массивов оставлять один пробел.

Пример:

```js
if (userAge >= 18 && isActive) {
    const numbers = [1, 2, 3, 4];

    for (const number of numbers) {
        const result = number * 2;

        if (result > 5) {
            saveResult(number, result);
        }
    }
}
```



## Переменные

- Использовать правила названий из раздела [Названия](#названия).
- Использовать `const` для неизменяемых значений, `let` для изменяемых значений, `var` не использовать.
- Объявлять переменные максимально близко к месту использования.
- Не объединять несвязанные переменные в одну группу.

Пример:

```js
const fileName = 'test.txt';

let fileSize = 0;

fileSize = getFileSize(fileName);

const userName = 'User';
const userRole = 'Admin';
```



## Функции

- Использовать правила названий из раздела [Названия](#названия).
- Функция должна выполнять одну логическую задачу.
- Количество параметров ограничивать, если возможно.
- Не создавать функции с большим количеством ответственности.
- Не изменять внешние данные без необходимости.

Пример:

```js
/* ***
 * loadFile - загрузка файла
 * - принимает путь к файлу
 * - проверяет существование файла
 * - загружает содержимое файла
 * - возвращает объект с данными файла
*** */
function loadFile(filePath) {
    if (!filePath) {
        return null;
    }

    const fileExists = checkFile(filePath);

    if (!fileExists) {
        return null;
    }

    const fileContent = readFile(filePath);

    const fileData = {
        path: filePath,
        content: fileContent,
        size: fileContent.length
    };

    return fileData;
}
```

- Функции должны явно возвращать результат, если он используется дальше.
- Не возвращать разные типы данных из одной функции без необходимости.
- Использовать `null`, если результат отсутствует.

Пример:

```js
function findFile(fileName) {
    if (!fileName) {
        return null;
    }

    return file;
}
```



## Обработчики событий

- Использовать правила названий из раздела [Названия](#названия).
- Перед каждым обработчиком событий (`addEventListener`) или группой связанных обработчиков обязательно размещать комментарий.
- Названия функций-обработчиков должны начинаться с `handle`.
- Обработчики событий должны содержать только логику обработки события.
- Сложную логику выносить в отдельные функции.
- Обработчики событий размещать после объявлений функций в конце логического блока.

Пример:

```js
/* ===
 * Обработчики событий редактора
=== */

/* ***
 * handleClick - обработка нажатия на элемент
 * - принимает объект события
 * - получает выбранный элемент
 * - выполняет действие при нажатии
*** */
function handleClick(event) {
    selectElement(event.target);
}

/* ***
 * handleInput - обработка изменения содержимого
 * - принимает объект события
 * - обновляет данные редактора
*** */
function handleInput(event) {
    updateContent(event.target.value);
}

// Добавление обработчиков событий редактора
element.addEventListener('click', handleClick);
element.addEventListener('input', handleInput);
```



## Область видимости

- Не создавать глобальные переменные без необходимости.
- Общие значения хранить в отдельных объектах или константах.
- Переменные использовать только в той области видимости, где они необходимы.
- Не изменять переменные из внешней области без необходимости.
- Не создавать функции внутри других функций.

Пример:

```js
// Состояние редактора
const editorState = {
    selectedElement: null,
    isLoading: false
};

/* ***
 * loadFile - загрузка файла
 * - принимает путь к файлу
 * - загружает содержимое файла
 * - возвращает данные файла
*** */
function loadFile(filePath) {
    const fileData = readFile(filePath);

    return fileData;
}
```



## Импорты

- Импорты размещать в начале файла.
- Не импортировать неиспользуемые зависимости.
- Группировать импорты по назначению.

Пример:

```js
import { loadFile } from './files.js';
import { saveFile } from './storage.js';
```



## Ошибки

- Ошибки обрабатывать через `try/catch`.
- Не игнорировать ошибки без необходимости.
- Сообщения об ошибках должны описывать причину возникновения.
- Не использовать пустой `catch`.

Пример:

```js
try {
    loadFile(filePath);
} catch (error) {
    console.error('Ошибка загрузки файла:', error);
}
```

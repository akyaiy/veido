# Стилистика CSS

Правила оформления CSS кода проекта - структура, форматирование и использование стилей.



## Названия

- Использовать понятные и короткие названия.
- Название должно описывать назначение элемента.
- Использовать `camelCase` для названий.
- Избегать непонятных сокращений и не делать названия длиннее 3 слов.



## Пробелы и отступы

- Использовать (табуляцию) отступы в 4 пробела.
- Между стилями разных классов оставлять одну пустую строку, а между разными блоками CSS - 3 пустые строки.



## Форматирование CSS

- Свойства внутри класса записывать в формате `название: значение;`.
- Свойства внутри блока располагать каждое с новой строки.
- Не использовать `!important` без необходимости.                            

Пример:

```css
.svgIcon {
    width: 20px;
    height: 20px;
}

input[type="checkbox"]:checked {
    width: 20px;
    height: 20px;
}
```

- Селекторы перечислять через запятую, каждый селектор размещать с новой строки.

Пример:

```css

.leftPanel,
.rightPanel {
    width: 100%;
    overflow-y: auto;
}
```

- Не использовать глубокую вложенность селекторов без необходимости.
- Максимально ограничивать вложенность селекторов до 2-3 уровней.
- Вложенные селекторы записывать в одну строку.

Пример:

```css
.leftPanel .editorBlock {
    width: 100%;
    overflow-y: auto;
}
```

- Внутри условий сохранять обычное форматирование CSS.
- Отступы внутри условий должны быть увеличены на один уровень вложенности.

Пример:

```css
@media (max-width: 768px) {
    .leftPanel {
        width: 100%;
        overflow-y: auto;
    }

    .mainContainer {
        flex-direction: column;
        height: auto;
    }
}
```



## Структура и комментарии

- Код должен разделяться на логические блоки с помощью однострочных комментариев формата `/* Название раздела */`.
- Не дублировать одинаковые стили в разных блоках.

Пример:

```css
/* Общие стили */
.svgIcon {
    width: 20px;
    height: 20px;
}



/* Кнопки */
.saveButton,
.cancelButton {
    background-color: #000000;
}

.saveButton {
    color: #ffffff;
}

.cancelButton {
    color: #ff0000;
}
```
